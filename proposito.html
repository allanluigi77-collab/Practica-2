Objetivos del Proyecto

El propósito principal es aplicar de manera individual conocimientos de maquetación web estructurando contenidos de forma limpia y profesional.

Como objetivos principales de esta actividad se contemplan los siguientes puntos clave:

  • Implementar una distribución de página (layout) profesional y uniforme mediante el uso de contenedores estructurales obligatorios como el encabezado, la barra lateral, el contenido principal y el pie de página.
  • Aplicar reglas de estilo centralizadas a través de un archivo CSS externo, garantizando la consistencia visual y estética en la totalidad de las páginas que componen el sitio.
  • Integrar de forma correcta todos los elementos técnicos exigidos por la rúbrica académica, tales como jerarquía de encabezados, listas anidadas tanto numeradas como no ordenadas, tablas de datos estilizadas, y elementos tipográficos de énfasis como negritas y cursivas.
  • Asegurar una navegación intuitiva, fluida y accesible para cualquier usuario mediante el uso de hipervínculos uniformes y un mapa de sitio funcional.
    •

En definitiva, esta práctica representa un ejercicio clave para demostrar la capacidad de análisis, diseño y codificación individual, reflejando el rigor técnico y la atención al detalle en el desarrollo de soluciones web funcionales.
